# Library Management System

A web-based Library Management System developed as an academic project to help organize and manage library operations, book records, and borrowing activities.

This project was originally developed as a school project. The source code is preserved, but the original database was lost. A database reconstruction and system improvement are planned for a future redevelopment phase.

## About the Project

The Library Management System aims to provide a centralized platform for managing library resources and organizing book-related transactions.

## Future Feature: QR Code Integration

One of the planned improvements is integrating **phpqrcode-master** into the Library Management System.

The purpose of this feature is to introduce QR Code-based book identification and improve the efficiency of library transactions.

### Planned QR Code Functionality

- Generate a unique QR code for every registered book.
- Associate each QR code with a specific book record.
- Scan QR codes to retrieve book information.
- Simplify book identification during borrowing and returning.
- Reduce manual book searching and data entry.

### Planned Implementation

The phpqrcode-master library will be evaluated and integrated during redevelopment.

The intended workflow:

1. An administrator registers a new book.
2. The system assigns a unique book identifier.
3. A QR code is generated using the book identifier.
4. The QR code is printed and attached to the physical book.
5. Library personnel scan the QR code to retrieve the corresponding book record.

**Note:** QR Code integration is a planned feature and has not yet been implemented.
